Automation Ready Schema

This system is designed so standard GitHub Actions scripts can push data directly to Firestore without paid Firebase functions.

External Script Workflow:

  1. Script scrapes official websites daily.
  2. Finds a matching existing exam doc.
  3. If dates changed, script updates doc setting changesDetected: true and adds an oldValues map.
  4. If new, pushes a doc with status: 'pending_review'.
  5. Admin reviews in this UI, approves (which flags it verified: true and clears change flags).

Note: Real-world scripts authenticate with a Service Account to bypass client security rules. Admin actions here modify standard /artifacts/appId/public/data/exams path.
